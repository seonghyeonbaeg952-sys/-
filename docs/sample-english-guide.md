# 영어 버전 사용 및 관리

## 적용 범위

- 공개 홈페이지 `/`와 `/sample/`에서 한국어·영어를 전환할 수 있습니다. 쿼리가 없는 공개 홈페이지는 한국어가 기본입니다.
- 헤더의 **EN**으로 바꾸면 현재 페이지·섹션·해시를 유지한 채 영어로 이동합니다. **KR**로 돌아올 수 있습니다. 샘플 안에서 선택한 언어는 샘플에서만 기억됩니다.
- `/?lang=en`과 `/sample/?lang=en`은 각각 공개 홈페이지와 샘플의 영어 화면입니다. 관리자 화면은 한국어로 유지됩니다.
- 기존 이미지·포스터 안의 글자, 공식 영문명이 확인되지 않은 이름, 번역하지 않은 신규 게시글은 한국어 원문을 유지합니다.
- `/sample/`의 입단·문의·후원약정은 입력·검토·서명을 시험할 수 있지만 **실제 접수하지 않습니다**. 원본 홈페이지의 두 언어에서는 기존 접수 흐름을 그대로 사용합니다.

## CMS에서 영어 수정

1. 관리자 로그인 후 **영어 버전 변경** 메뉴를 엽니다. 직접 주소는 `/admin/editor-english`입니다.
2. 홈·정신·소개·공연 등 편집할 화면과 기기를 선택합니다.
3. 미리보기에서 문구를 선택하거나 **문구 찾기·바꾸기 도구**를 사용합니다. 기존 글자별 서식·상자 배치 편집을 재사용합니다.
4. 헤더·푸터와 고정 안내 문구는 **공통**에서 관리합니다. 공지·갤러리 등 개별 게시물은 아래의 **항목별 한국어·English 버전** 기능에서 수정합니다. 프로필 등 기존 원문 기반 번역 항목은 공통 검색으로 계속 찾을 수 있습니다.
5. **영어 버전 임시저장** 후 미리보기로 확인합니다. 저장만으로 방문자에게 반영되지 않습니다.
6. **영어 버전 게시**를 눌러 확인하면 공개 홈페이지와 `/sample/`의 English 화면에 반영됩니다. 한국어 초안·게시본은 바뀌지 않습니다.
7. 잘못 편집했다면 실행 취소 또는 게시 이력의 **초안으로 불러오기**를 사용합니다. 복구 역시 다시 게시하기 전에는 공개되지 않습니다.

기기를 바꿔도 입력한 초안은 유지됩니다. 한국어 원문이 기기별로 다르면 해당 기기의 원문을 기준으로 영문 기본값을 보여줍니다. 다른 작업으로 이동할 때 미저장 입력은 기존 이탈 방지 기능으로 보호합니다.

## 번역과 원본의 관계

고정 문구는 기존 CMS 항목 ID를 유지합니다. 공통 사전의 원문 기반 번역은 원문에서 계산한 식별자를 사용합니다. 개별 게시물의 English 버전은 **콘텐츠 종류 + 원본 UUID**로 저장하므로 제목이 같은 두 공지도 서로 다르게 수정할 수 있습니다. 원본을 수정해도 별도로 작성한 English 버전은 자동으로 덮어쓰지 않습니다. 원본을 고친 뒤에는 관리자가 영어 내용도 확인하세요.

새 콘텐츠를 등록한 뒤에는 영문 편집 화면을 새로 열어 목록을 갱신하세요. 확인되지 않은 인명·기관명은 관리자가 공식 표기를 확인한 뒤 번역하는 것이 안전합니다.

## 항목별 한국어·English 버전

지원하는 관리 메뉴는 공지, 갤러리, 공연, 영상, 포스터, 홈 슬라이드, 홈 팝업, 연혁, 자주 묻는 질문, 소개 섹션, 지휘자, 반주자, 단원 설명, 후원사, 사이트 설정, 오시는 길, 입단 안내, 후원 설정 **18종**입니다. 단원 이름·공개 설정은 언어별로 바꾸지 않습니다.

1. 새 항목은 기존 관리 화면에서 한국어와 날짜·분류·공개 여부 등 공통정보를 등록합니다.
2. 목록에서 **English 작성·수정**을 누릅니다. 한국어 원문을 확인하면서 영어 제목·내용을 입력할 수 있습니다.
3. 이미지·포스터·영상은 영문용 자료를 따로 등록할 수 있습니다. 비워 둔 영문 항목은 원본 자료를 사용하며, 기존 문구 사전에 번역이 있으면 그 번역을 표시합니다.
4. **영문 임시저장**을 누릅니다. 이미지 업로드만으로 게시되지는 않습니다.
5. **저장된 영문 콘텐츠 미리보기**에서 저장한 문구와 원본 비율을 유지한 이미지를 확인합니다. 이 미리보기는 해당 콘텐츠 확인용이며 실제 홈페이지 전체 배치의 픽셀 검사를 대신하지 않습니다.
6. **영어 버전 게시**를 누르면 공개 홈페이지와 `/sample/`의 영어 화면에 반영됩니다. 원본이 비공개이면 영어 게시본도 공개 목록에 나오지 않습니다.
7. 목록의 English 열은 **원본 사용 / 영문 초안 / 영문 게시본** 상태를 표시합니다. 게시본이 있는 항목의 새 변경사항은 편집 창에서 ‘게시 전’ 상태로 확인합니다.

현재 페이지 목록에서는 영문 상태별 필터와 건수를 볼 수 있습니다. 영문 편집 창은 채워진 항목 수, 글자·단어 수, 게시본과 달라진 필드를 보여줍니다. 제목·버튼의 권장 길이는 안내이며 저장을 막거나 문구를 자르지 않습니다. 상태를 불러오지 못하면 모든 한국어 행을 유지하고 재시도를 안내합니다.

사이트 설정·오시는 길·입단 안내·후원 설정은 각 관리 메뉴에서 **English 버전 작성·수정**을 엽니다. 먼저 한국어 원본을 저장해야 하며, 연락처·계좌·금액·일정·공개 여부는 두 언어가 공유합니다. 영어 전용 문구와 허용된 이미지만 별도로 임시저장·게시합니다.

영문 버전의 저장·게시 버전은 한국어와 독립적입니다. 다른 관리자가 먼저 저장한 경우 덮어쓰기를 거부하고 입력을 유지합니다. 한국어 원본을 삭제하면 English 버전도 공개 목록에서 제외됩니다. 날짜·분류·관련 공연·공개 여부는 한국어 항목의 공통정보를 기준으로 합니다.

## 영문 양식 날짜

영문 입단지원서와 후원약정은 브라우저 기본 달력 대신 **Month / Day / Year**를 표시합니다. 월 이름은 영어이며, 2월의 윤년과 월별 일수를 확인하고 연도는 네 자리로 입력합니다. 일부만 입력한 날짜는 양식을 확인하기 전에 완성해야 합니다. 선택 중인 날짜는 **Clear date**로 한 번에 지울 수 있습니다. 실제 저장값은 기존 `YYYY-MM-DD` 형식입니다. 한국어 화면의 날짜 입력과 기존 서명·접수 값은 유지합니다.

## 관리자 인쇄

입단지원서와 후원약정 목록의 **상세·인쇄**에서 기존 인쇄 동작을 바로 찾을 수 있습니다. 공개 홈페이지의 한국어·영어 양식에서 접수된 답변은 저장된 원문을 그대로 출력하며, 후원약정의 당시 약관·서명과 기존 개인정보 보호 규칙도 유지합니다. 샘플에서는 실제 접수가 차단되므로 샘플 입력을 CMS 인쇄 목록에서 찾을 수는 없습니다. 인쇄 문서의 관리용 고정 라벨은 현재 한국어이며, 별도 영문 인쇄 서식은 아직 제공하지 않습니다.

## 저장 및 운영

영문 전용 테이블은 `sample_english_editor_pages`, `sample_english_editor_revisions`입니다. 원본의 `site_editor_pages`와 이력·버전·게시 RPC·캐시를 공유하지 않습니다. 관리자만 초안을 읽거나 수정할 수 있고, 방문자는 게시된 영문 문서만 조회합니다.

관련 마이그레이션: `supabase/migrations/20260927163328_add_sample_english_editor.sql`.

게시물의 영문 버전은 별도 `sample_english_content` 테이블을 사용합니다. 기본 마이그레이션은 `supabase/migrations/20260927182316_add_sample_english_content.sql`, 운영 설정 네 종류 확장은 `supabase/migrations/20260928101542_sample_english_operation_settings.sql`, 프로필 확장은 `supabase/migrations/20260928110700_extend_english_profiles.sql`입니다. 기존 공개 기록은 `scripts/backfill-english-content.sql`로 영어 게시본을 채웠습니다. 이 스크립트는 이미 작성된 영문 초안·게시본을 덮어쓰지 않습니다. 항목마다 초안·게시본·버전이 분리됩니다. 조회가 실패하면 영어 화면에서 재시도할 수 있고, 정상적으로 조회한 게시본이 같으면 불필요하게 페이지 데이터를 갱신하지 않습니다.

별도 번역 서비스·API 키·운영 의존성은 추가하지 않았습니다. 영어 버전은 공개 홈페이지에 표시되지만 한국어 원본을 덮어쓰지 않습니다. `사이트 소개 한 줄`로 불리던 설정은 현재 소개 페이지의 검색 결과용 메타 설명에 사용되고, 본문·푸터에는 표시되지 않습니다. 관리 화면의 라벨도 이 위치를 나타내도록 바꿨습니다.

## 확인 범위

단위/상태/서버 렌더링/DB 권한 검사를 수행했습니다. 사용자 지시에 따라 컴퓨터 유즈와 실제 브라우저 조작은 하지 않았습니다. 따라서 실제 기기의 줄바꿈·겹침·스크롤 모션·인쇄 결과는 시각 검증이 추가로 필요합니다.

자세한 근거는 `docs/sample-english-verification.md`를 참고하세요.
