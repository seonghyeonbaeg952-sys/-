# CMS 플로팅 글자 편집창 Figma 보완

2026-09-18. 기존 CMS 648:1688과 모바일 652:1727을 보존하고 별도 복제 시안을 제작했다.

- [Desktop 1440](https://www.figma.com/design/nz8fKU1RqfasYhsIQEIVF5/SMYC?node-id=691-2711)
- [Mobile 390](https://www.figma.com/design/nz8fKU1RqfasYhsIQEIVF5/SMYC?node-id=691-2897)

## 구조

- 기존 상단 서식 리본 대신 400px 비모달 글자 모양 창을 사용한다. 선택한 본문과 캔버스를 계속 볼 수 있다.
- 제목줄 이동, 왼쪽/오른쪽 배치, 접기 조작을 표현한다. 임시저장과 게시 버튼은 기존 별도 영역에 유지한다.
- 선택 범위 → 글꼴/크기 → 색/굵게/기울임/밑줄 → 추가 서식 → 실행취소/다시실행/수정 마치기 순서다.
- 모바일에서는 358px 창에 도구를 재배치하고, 별도 위치 버튼과 긴 도움말은 숨긴다. 선택한 큰 제목은 창 위에서 볼 수 있도록 배치한다.
- 기존 여섯 글꼴 선택 패널, 색 선택 패널, 추가 서식 패널로 오버레이 연결을 추가했다.
- 모든 주요 버튼 높이 44px. 모바일 `기울임`이 두 줄로 나뉘는 문제를 발견하고 너비를 보정했다. 글꼴·크기·색·추가서식에 테두리를 넣어 클릭 가능성을 명확하게 했다.

## 검증 범위

Figma 스크린샷으로 전체 desktop/mobile과 플로팅 창을 확대 확인했다. 이 파일은 디자인 시안 기록이며, 실제 드래그/접기/저장 동작을 Figma로 구현하거나 코드 실행을 검증한 기록은 아니다. 해당 기능 검증은 CMS 구현 테스트에서 별도로 수행한다.

이 디자인 작업으로 공개 홈페이지 코드와 공개 콘텐츠는 변경하지 않았다.
