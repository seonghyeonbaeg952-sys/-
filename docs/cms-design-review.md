# CMS 디자인 검토 — Quiet Workspace

대상: 기존 Figma 파일의 `CMS / Quiet Workspace / 2026-09-17` 페이지(609:1253).
범위: 실제 CMS 작업을 대표하는 18개 화면/상태 시안. 모든 개별 CRUD 화면을 복제한 것은 아니다. 문구·디자인 편집과 기존 콘텐츠 관리, 접수 관리의 다른 저장 책임을 구분한다.

## 그대로 유지할 구현 경계

- 공개 홈페이지 디자인·스크롤바·영어 기능은 변경하지 않는다.
- CMS 서체/색/간격은 관리자 shell 및 관리자 modal 안으로만 한정한다.
- Figma의 소개 미리보기는 기존 소개 시안의 배치 참고물이다. 실제 CMS iframe은 현재 홈페이지를 표시하며, 위 참조 이미지를 코드에 넣지 않는다.
- 날짜·전화번호·공연·지원서는 모두 디자인용 가상 예시다. 운영 DB로 넣지 않는다.
- 정적 시안의 기능 없는 검색/선택 모양을 구현 완료로 간주하지 않는다. 실제 CMS에서 키보드·모달·브라우저 뒤로가기·저장 실패를 별도 검증한다.
- 포커스 도안은 접근성 자동 인증이 아니다. 실제 브라우저 및 200% 확대 검증이 남아 있다.

## 자료 확인 범위

기존 코드와 Figma 로컬 컴포넌트, Simple Design System 버튼·입력창, GOV.UK 오류 요약/확인 패턴, Sanity 초안·미리보기 문서를 참고했다. 20,000개 자료를 실제 검토했다고 주장하지 않는다.

## 구현 단계 현황

검토한 대표 패턴을 관리자 전용 코드에 적용했다. 편집기·모달·원문/인쇄·모바일 설정의 실제 검증은 `cms-browser-qa-progress.md`에 기록한다. 긴 문구 목록은 20개씩 확장하고 검색 중 편집해도 입력창이 사라지지 않도록 보완했다. 전체 계획 및 모든 화면의 최종 적용 완료와는 구분한다.
