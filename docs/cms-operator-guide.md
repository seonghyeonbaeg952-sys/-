# 홈페이지 관리자 사용 설명서

2026-09-17 · 현재 구현 기준. 운영 계정·비밀번호·접수 개인정보는 이 문서에 적지 않습니다.

## 먼저 알아두세요

- **홈페이지 편집 · 미리보기**: 버튼 이름, 안내 문구, 기기별 글꼴·크기·색을 다룹니다. `임시저장`과 `이 화면 게시`가 분리됩니다.
- **콘텐츠 관리**: 공연, 공지, 인물 약력, 사진, 연혁, 모집·후원 안내의 실제 원본을 다룹니다. 기존 콘텐츠의 `저장`은 공개 설정에 따라 바로 홈페이지에 반영됩니다. 이 화면의 저장을 새 편집기의 임시저장과 혼동하지 마세요.
- **접수함**: 지원서·문의·후원약정 원문을 확인하고 처리 상태와 메모를 관리합니다. 원문을 디자인 문구처럼 고치는 곳이 아닙니다.
- 공개 홈페이지 디자인의 기본값은 유지됩니다. 편집값을 직접 게시하지 않으면 새 서체나 색이 자동 적용되지 않습니다.

## 1. 문구 한 줄 바꾸기

1. 관리자 메뉴에서 **홈페이지 편집 · 미리보기**를 엽니다.
2. **편집할 화면**에서 입단 안내, 공연, 공지 등 대상을 고릅니다.
3. **이 변경을 적용할 기기**를 고릅니다. `공통`은 기기별 값이 없는 곳의 기본값입니다. 모바일만 바꾸려면 `모바일`을 선택합니다.
4. **문구 찾기**에 홈페이지에서 본 단어나 항목명을 입력합니다. **화면 안 위치**로도 좁힐 수 있습니다.
5. 필요한 문구를 수정합니다. 검색한 단어를 다른 말로 바꾸어도 입력창은 사라지지 않습니다. 새 검색을 입력하면 검색 결과가 갱신됩니다.
6. **미리보기**에서 실제 홈페이지와 줄바꿈을 확인합니다. 작은 화면에서는 편집/미리보기 버튼으로 전환합니다.
7. **임시저장**을 누르고 완료 안내를 확인합니다. 이 단계에서는 방문자 화면이 바뀌지 않습니다.
8. **이 화면 게시**에서 변경 목록과 적용 기기를 확인한 뒤 게시합니다. 다른 화면의 초안을 함께 게시하지 않습니다.
9. **공개 화면 보기**에서 결과를 확인합니다. 열려 있던 홈페이지에는 게시본 갱신 시간이 있을 수 있으므로 새로고침하여 확인합니다.

문구는 처음 20개씩 표시됩니다. 아래 **문구 더 보기**로 추가 항목을 엽니다. 펼치거나 검색을 바꾸어도 입력한 초안은 유지됩니다. 브라우저 창 자체를 닫기 전에는 반드시 임시저장하세요.

### 공통·모바일·태블릿·데스크톱 관계

해당 기기에 입력한 값 → 공통 입력값 → 기존 홈페이지 원문 순서로 사용합니다. 기기별 값이 있으면 공통 변경만으로 그 값을 덮어쓰지 않습니다.

- 내용을 전부 지우면 **빈 문구**로 저장합니다.
- **공통값 사용** 또는 **원문으로 되돌리기**는 직접 입력값을 제거하고 위의 기본값을 사용합니다.
- 기존 홈 화면 문구는 기기별 원본이 있으므로 홈의 모바일·태블릿·데스크톱에서 편집합니다.
- 미리보기 기기와 편집 적용 기기는 별개입니다. 모바일 문구를 편집하면서 PC 미리보기를 선택해 PC가 바뀌지 않는지 확인할 수 있습니다.

## 2. 글자 선택 편집과 페이지 전체 서식

**문구**에서 화면에 보이는 문장을 검색하고 목록에서 한 항목을 선택합니다. **문구 입력** 칸에서 글자를 드래그하거나 Shift+방향키로 선택하세요. 위에 “선택: … · 이 글자에만 적용”이 나오면 **글꼴**, **크기(px) → 크기 적용**으로 선택 부분만 수정합니다. 문장 전체는 **전체 글자 선택**을 먼저 누르세요.

- 글자 서식은 기존 여섯 글꼴과 10–120px를 지원합니다. 선택하지 않으면 도구가 비활성화됩니다.
- **선택 서식 지우기**는 선택 부분만, **실행 취소/다시 실행**은 현재 문구의 최근 입력·서식을 되돌립니다. Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z도 사용할 수 있습니다.
- 아래 서식 미리보기는 글자 모양 확인용입니다. 실제 줄바꿈과 배치는 옆의 **홈페이지 미리보기**에서 확인하세요.
- 내용 입력은 일반 텍스트입니다. 글자별 서식은 별도로 안전하게 저장되며 HTML을 붙여 넣는 방식이 아닙니다. 새로 삽입한 문자는 기본 서식이고 기존 문자의 서식 범위는 재계산됩니다.
- 주소·대체 텍스트·숨김 안내·일부 동적 문자열처럼 서식 출력에 연결되지 않은 항목에는 글자 서식 도구가 나오지 않습니다. 일반 문구 수정은 가능합니다. 구형 브라우저에서는 문구 입력만 제공할 수 있습니다.
- 편집은 초안입니다. **임시저장 → 미리보기 확인 → 이 화면 게시** 순서를 유지합니다. 서식도 문구와 함께 이력·충돌 검사에 포함됩니다.

**페이지 전체 서식**은 선택한 글자가 아니라 해당 페이지·기기 전체의 기본 서체·크기·색상 설정입니다. 글자별 서식이 지정된 부분은 그 지정값을 우선합니다. 글꼴 파일이나 외부 스크립트 주소를 입력하는 방식은 지원하지 않습니다. 잘못된 범위나 색상은 저장할 수 없습니다.

초안은 세 기기의 미리보기에서 확인하세요. 긴 제목·작은 화면에서 잘리지 않는지, 글자와 배경이 충분히 구분되는지 확인합니다. 색만으로 필수 항목이나 상태를 구분하지 마세요.

**편집값 초기화**는 해당 범위의 직접 입력값을 제거합니다. **이 화면 전체 초기화**는 다른 화면이나 공연·약정 원문을 지우지 않습니다. 초기화도 별도의 임시저장·게시가 필요합니다.

잘못 게시했다면 **게시 이력 → 초안으로 불러오기**를 사용합니다. 과거 버전은 곧바로 공개되지 않고 초안으로 들어옵니다. 미리보기 후 다시 게시하세요.

## 3. 저장 실패·동시 편집·이탈 경고

- 저장 중 다시 누르지 마세요. 요청이 끝나기 전에 추가로 입력한 내용은 별도의 미저장 변경으로 남습니다.
- 연결 오류가 나면 입력을 유지한 채 재시도할 수 있습니다. 성공 안내가 없으면 저장된 것으로 간주하지 마세요.
- 다른 관리자가 같은 항목을 수정하면 **겹친 변경 확인**이 나옵니다. 서버값과 내 입력을 비교해 항목별로 선택합니다. 자동으로 남의 내용을 덮어쓰지 않습니다.
- 다른 메뉴·뒤로가기에서 **계속 편집**을 고르면 입력이 유지됩니다. 나가기를 선택하면 아직 저장하지 않은 해당 화면의 작업을 잃을 수 있습니다.
- 새로고침·창 닫기는 브라우저 기본 경고를 사용합니다. 브라우저나 기기 종료 시 모든 입력 복구가 보장되는 것은 아닙니다.

## 4. 사진·공연·공지 같은 원본 관리

편집기 아래 **실제 내용은 여기에서 관리합니다** 링크나 관리자 업무 메뉴를 사용합니다. 인물 이름·약력, 공연 날짜와 장소, 모집 기간, 후원약정 본문은 이 원본 화면에서 수정합니다.

이미지는 `파일 선택 → 미리보기 → 선택한 이미지 업로드 → 성공 확인 → 콘텐츠 저장` 순서입니다. 선택만 했거나 업로드 중·실패 상태이면 저장이 차단됩니다. **선택 취소**는 기존 저장된 이미지 주소를 유지합니다. 파일을 골랐다는 이유만으로 기존 파일을 삭제하지 않습니다.

일반 사진은 JPG·PNG·WebP, 로고 입력에서 허용한 경우에만 SVG를 사용합니다. 파일 크기·형식이 맞지 않으면 원본 이미지를 다시 내보내세요. 파일 확장자만 바꾸는 것은 변환이 아닙니다.

**현재 보안상 주의:** 기존 `site-images`는 공개 저장소입니다. 업로드 후 CMS에서 비공개로 설정해도 파일 주소 자체가 비공개가 되지는 않습니다. 개인정보 문서·비공개 청소년 사진을 이 이미지 업로더에 올리지 마세요. 안전한 비공개 업로드/게시 전환 작업은 아직 완료되지 않았습니다.

## 5. 접수함과 인쇄

### 홈 팝업 관리

팝업 내용 → 연결 버튼 → 노출 기간 → 표시 설정의 네 구역으로 나뉩니다. 종료일은 시작일과 같거나 이후여야 합니다. 잘못 입력하면 종료일 아래 안내가 나오고 저장되지 않습니다. 시작일·종료일을 비우면 해당 경계에 제한이 없습니다. 날짜를 임의로 바꿔 저장하지 않으므로 원하시는 기간을 직접 확인하세요. 공개 여부와 노출 기간을 모두 충족해야 방문자에게 보입니다.

- **입단지원서**: 원문과 접수 정보를 확인한 뒤 상태·내부 메모만 관리합니다. 불필요한 접수는 영구 삭제 대신 보관 흐름을 사용합니다. 과거 첨부 파일을 지우지 않습니다.
- **후원약정**: 접수 답변, 동의, 서명 및 **접수 당시 약정 원문**을 확인합니다. 새 약정은 당시 원문 스냅샷이 보존됩니다. 옛 접수에 스냅샷이 없다면 확인 불가로 표시하며 지금의 약정을 과거 원문으로 꾸며 넣지 않습니다.
- **인쇄**: 상세 화면의 인쇄 버튼으로 원문을 출력합니다. 내부 수정 컨트롤과 관리자 메뉴는 제외됩니다. 브라우저 인쇄 미리보기에서 용지·배율·페이지 나눔을 마지막으로 확인하세요.
- 서명 이미지를 보존하는 것은 서명자의 신원 확인이나 법적 효력을 자동 보증하는 기능이 아닙니다.
- 문의·후원약정 접수 완료는 입단지원 완료나 후원금 납부 완료와 다릅니다.

## 6. 운영 설정

연락처·위치 정보는 해당 원본 메뉴에서 한 번만 관리합니다. 같은 위치 정보를 여러 화면에서 따로 입력할 필요가 없습니다.

**접수 보호 설정 · 고급**은 한 시간 동안 허용할 접수량입니다. 실제 현재값을 읽어 표시하고 명시적으로 저장할 때만 바뀝니다. 전체 한도와 연락처별 한도를 혼동하지 마세요. 저장 충돌이 나면 최신값을 확인하고 다시 판단합니다. 이 기능은 본인 인증·IP 차단·대규모 네트워크 공격 방어가 아닙니다.

## 7. 운영자가 하면 안 되는 일

- 키·관리자 비밀번호·지원서 개인정보를 공개 안내문에 붙여 넣기
- 실제 신청자 원문이나 서명을 테스트용으로 수정하기
- 미리보기에서 접수 버튼을 눌러 실제 접수가 되었다고 생각하기: 미리보기의 실제 접수는 차단됩니다.
- 오류를 해결하려고 Supabase RLS나 관리자 권한 검사를 끄기
- 홈페이지에 남은 예전 예시 데이터를 이번 검증 자료라고 단정해 일괄 삭제하기

## 구현과 확인 범위

전체 승인서가 아니라 현재 사용 흐름 안내입니다. 구현·실행 증거, Storage·배포 경계, 실물 인쇄·실기기·전체 문구 연결의 잔여 범위는 `cms-audit-results.md`, `cms-browser-qa-progress.md`, `site-editor-copy-coverage.md`를 함께 확인하세요.
