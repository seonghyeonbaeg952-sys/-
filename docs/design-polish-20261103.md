# 공개 홈페이지 문구·배치 개선 검수

2026-11-03

## 변경한 내용

- 정신 마지막 제목을 **서울모테트청소년합창단과 / 함께하세요.**로 정리했다. 입단·후원 설명도 실제 행동을 안내하는 문장으로 바꿨다.
- 네 개의 독립 이동 문구를 `spirit.content.cta.title` 한 개의 CMS 제목으로 통합했다. 실제 보이는 문장과 다른 접근성 이름도 제거했다.
- 마지막 섹션의 제목·설명·버튼을 내용에 따라 늘어나는 그리드로 바꾸고, 로고와 ONE VOICE를 별도 영역에 배치했다. 기존 고정 좌표와 중복 반응형 규칙을 정리했다.
- 한국어·영어 및 세 기기 저장본을 맞췄다. 모바일 홈 소개 제목에서 빠졌던 ‘다음’을 복원하고 영어 기본 문구도 통일했다.
- SPIRIT 제목의 진입 동작과 왼쪽 이동값을 조정해 제목이 화면 밖에서 시작하는 문제를 줄였다. 사용자가 정한 다른 데스크톱 서식은 보존했다.
- 모바일 VOICE를 끊던 CMS 99.3% 상자 너비를 정리했다.
- 단원 소개의 중복 제목은 명단 영역의 접근성 제목으로 유지하고, 반복 설명·개인정보 안내를 명단 아래에 배치했다.
- 반주자 소개의 고정 높이·절대 좌표를 풀고 제목·장식·여백·모바일 인물 크기를 조정했다.
- 접힌 모바일 메뉴에 inert를 적용했다. 현재 표시되는 지휘자·반주자 메뉴의 CMS 서식 지원 목록도 실제 렌더러와 일치시켰다.
- 사진 대체 설명에 파일 제목 ‘4’가 노출되던 항목을 실제 공연 장면을 설명하는 한영 문구로 정리했다.

## UX 개선점

- 단원 첫 이름이 390px 화면에서 y=904px에서 y=659px로 약 245px 앞당겨졌다.
- 설명과 버튼이 제목의 실제 높이를 따라 배치된다. 문구를 길게 편집하거나 영어로 전환해도 이전처럼 문장 조각을 개별 좌표로 맞출 필요가 줄었다.
- 닫힌 메뉴 링크를 Tab으로 밟지 않는다. 열린 메뉴 접근과 Escape 후 트리거 복귀를 유지했다.
- 장식은 본문·버튼과 구분하고, 실제 문장·포커스·안내가 먼저 읽히도록 정리했다.

## 검증한 내용

- `pnpm lint`: 통과.
- `pnpm build`: TypeScript 및 Vite 빌드 통과.
- 변경 범위 직렬 테스트: **129/129 통과**.
- 메뉴 CMS 메타데이터 관련 테스트: **23/23 통과**. 수정 전 실패와 수정 후 통과를 확인했다.
- 전체 `pnpm test` 재검사: **1,214 통과 / 11 건너뜀 / 파일 종료 오류 1건**. SiteImage 테스트의 3개 검사는 완료됐지만 해당 파일 프로세스가 실패로 종료됐다. 동일 파일 단독 재실행은 **3/3 통과**, 종료 코드 0이다. 전체 명령을 전부 통과했다고 표시하지 않는다.
- Impeccable 변경 UI 파일 정적 검사: 발견 항목 없음.
- 공개 주요 8개 경로의 한영 390·1900px 배치를 확인했다. 홈 초기 로딩 중 관찰은 최종 상태와 구분해 다시 확인했다.
- 단원·반주자: 한영 390·768·1440px 12개 조합에서 가로 넘침과 깨진 이미지 없음.
- 정신 마무리: 한영 320·390·768·1440·1900px에서 제목·설명·버튼 배치를 확인했다. VOICE는 좁은 영어 화면에서 재검사 후 한 줄 표시를 확인했다.
- 메뉴: 영어 390px, 한국어 768px에서 접힌 링크 건너뛰기, 펼친 링크 접근, Escape 포커스 복귀 확인.
- CMS: 저장 문서 검증 함수 통과, 초안과 게시본 일치 확인. 한국어 홈 버전 32, 한국어 정신 153, 영어 정신 91.
- 동시 변경을 감지한 첫 저장은 중단됐고, 다른 홈 편집을 보존한 최신 문서에 요청 필드만 합쳐 다시 저장했다.

검수 로그·이미지는 로컬 `20261103-design-polish` 및 `20261103-profile-polish` 폴더에 보관했다.

## 조사한 내용

- Hallmark 2.0.0과 Impeccable 4.8.0을 기존 브랜드의 문구·타이포·구도 검수에 사용했다.
- 공식 제작사 사례 8개를 확인했다. 장식 후보 14개와 위치·동작·모바일 처리·과밀 위험은 [장식 후보 보고서](design-ornament-candidates-20261103.md)에 정리했다.
- [MDN inert 문서](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/inert)로 접힌 메뉴의 포커스·접근성 트리 처리를 확인했다.
- Supabase 변경 기록과 프로젝트의 저장·게시·버전 검사 구조를 확인했다.

장식 우선 후보는 공연 날짜 활자, 갤러리 열린 모서리, 소개 사진 세로 캡션, 입단 절차 대괄호다. 추가 후보는 검토용이며 일괄 적용하지 않았다.

## 남은 리스크

- 전체 테스트의 단발성 파일 종료 오류 원인은 확정하지 못했다. 단독 재실행이 통과한 기록을 보존했다.
- 실제 iOS/Safari 기기, 저속 네트워크 LCP 및 FPS는 측정하지 않았다.
- 홈의 대형 사진 원본 사용은 기존 선명도 선택을 유지한다. 이번 작업에서 전반적인 이미지 전달 정책을 바꾸지 않았다.
- 장식은 실제 화면에 여러 개를 동시에 넣으면 읽기와 성능을 해칠 수 있다. 추천 후보 중 서로 다른 내부 페이지 두 곳부터 비교하는 것이 적절하다.
