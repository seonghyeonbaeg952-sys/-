# CMS 화면 직접 편집 — Figma 시안 검토 기록

작성일: 2026-09-17

## 산출물과 범위

실제 홈페이지 화면에서 문구를 선택하고 직접 입력하는 CMS의 디자인 시안이다. 홈페이지를 새 디자인으로 바꾸는 작업이 아니다. 기존 Figma의 공지사항 화면과 CMS 버튼·색상 토큰을 재사용했다. 시안의 선택 테두리와 서식 도구는 관리자 전용이며, 일반 방문자 화면에는 나타나지 않아야 한다.

새 직접 편집 runtime은 아직 구현하지 않았다. 이전 글자별 서식·팝업 날짜 검증 작업의 테스트 통과 기록은 이 시안의 입력·저장 동작 검증으로 간주하지 않는다.

## 시안에서 연결한 흐름

문구 선택 → 글자 편집 → 편집 마침 → 임시저장 → 초안 저장됨 → 변경 확인·게시 → 게시 전 확인.

별도로 데스크톱에서 태블릿·모바일 상태로 이동하고, 저장된 초안에서 미리보기로 전환한 뒤 편집으로 돌아가는 연결을 넣었다. 모바일에는 편집 마침 → 임시저장 → 초안 저장됨 흐름을 연결했다. 게시 확인에서 더 편집하기는 확인 창을 닫는다.

Figma의 단계 이동용 프로토타입이다. 임의 텍스트 입력, 글꼴 목록 조작, 실제 임시저장·게시, 모바일 가상 키보드, 모든 관리 메뉴를 동작시키는 구현은 아니다. 최종 게시 버튼은 운영 홈페이지를 변경하지 않는다.

## 10개 검토 축

아래는 10개 축으로 수행한 자체 설계 검토다. 10회의 사용자 연구 또는 전체 브라우저 회귀 테스트를 수행했다는 의미가 아니다.

| 축 | 확인·수정한 사항 | 결과 / 남은 검증 |
|---|---|---|
| 1. 작업 직접성 | 실제 공지사항을 넓은 캔버스로 두고 별도 본문 입력창을 주 화면에서 제거 | 시안 반영. 실제 입력 runtime은 미구현 |
| 2. 선택 단위 | 블록 테두리만 있는 상태와 부분 글자 강조·커서 상태를 분리 | 시안 반영. 실제 Selection/Range는 구현 검증 필요 |
| 3. 기존 디자인 유지 | 기존 공개 페이지 프레임을 재사용. 예시의 ‘공지’ 2글자만 68→72px 서식 변경으로 표시 | 홈페이지 코드·공개 데이터 변경 없음. 실제 DOM 비교는 구현 단계 |
| 4. 시각적 우선순위 | 간결한 2행 도구, 넓은 캔버스, 좁은 문구 탐색 | 화면 캡처로 확인. 미리보기에서는 문구 탐색과 서식 도구를 숨김 |
| 5. 적용 범위 | 데스크톱/태블릿/모바일 표시 외에 ‘적용: 해당 기기’ 표시. 게시 확인에 영향을 받지 않는 기기도 표시 | 시안 반영. sourceDevice·shared 적용 검증은 구현 단계 |
| 6. 키보드·접근성 | Enter 진입, Ctrl+Enter 마침, Escape 취소 안내, 글자 편집 버튼 제공. 관리자 UI 글꼴 Gothic A1 확인 | 시안 검토. 실제 Tab 순서·포커스·스크린리더 미검증 |
| 7. 터치·작은 화면 | 390px 하단 도구·마침·취소 배치와 768px 도구 행 검토 | 관리자 버튼 높이 44px 미만 0개. 실제 키보드·safe area 미검증 |
| 8. 입력·복구 | 입력 마침을 별도 동작으로 두고 입력 중 임시저장·게시 비활성 상태 표시. 실행 취소·다시 실행 제공 | 시안 반영. IME·undo 동작은 구현 단계 |
| 9. 저장·공개 | 미저장/저장됨/미리보기/게시 확인을 별도 화면으로 구성. 저장된 화면에 남았던 미저장 안내 수정 | 단계 연결 확인. 실제 네트워크·충돌·공개 완료 상태는 미구현 |
| 10. 범위·유지보수 | 기존 버튼 인스턴스, 색상·간격 토큰 재사용. 복제 버튼에 남은 이전 화면 연결 89개 제거 | 최종 신규 시안 내부의 잘못된 목적지 연결 0개. 비가역 문구·동적 CMS는 계획의 capability 제한 적용 필요 |

## 최종 구조 검사

Figma Plugin API로 10개 프레임을 다시 읽어 확인했다. 기존 공개 홈페이지 참조 프레임 안의 요소는 CMS 크기 검사에서 제외하고, 관리자 UI 및 해당 부모의 가로·세로 범위를 검사했다. 홈페이지 캔버스의 의도적인 스크롤 창 자르기는 오류로 세지 않았다.

- 10개 프레임의 표시 중인 관리자 UI에서 부모 범위 밖 요소: 0개
- 관리자 동작 버튼 높이 44px 미만: 0개
- 관리자 텍스트 글꼴: Gothic A1
- 이전 시안·엉뚱한 목적지로 연결되는 프로토타입: 0개
- 신규 프레임 내부의 검토용 연결: 총 17개
- 데스크톱 입력·선택·초안 저장, 모바일, 태블릿, 게시 확인 화면 캡처 확인
- 부분 선택 강조가 불투명해 글자를 가리던 초기 오류를 노드 opacity 0.16으로 수정
- 서식 선택이 없는 상태의 글꼴·크기·서식 지우기를 비활성 표시

이 검사는 브라우저 구현의 반응형·보안·입력·서버 저장 테스트가 아니다.

별도로 `node --test scripts/public-copy-contract.test.mjs`를 실행하여 기본 JSX 문구·명시적 adapter·원래 강조 요소·줄바꿈·public 의존성 경계 검사 6개가 통과했다. 이것은 현재 저장소의 기존 public 출력 계약 검사이며 새 직접 편집 기능의 작동을 검증한 것은 아니다. 시안 단계에서는 전체 애플리케이션 빌드·실기기 입력 검증을 새로 실행하지 않았다.

## 조사와 다음 구현의 경계

UX Research·Interaction Design 지침에 따라 작업 흐름·상태·입력 복구를 나눴고, Figma 지침에 따라 기존 컴포넌트와 토큰을 재사용한 뒤 구조와 캡처를 점검했다. 실제로 연 공식 문서 10건과 채택 이유는 구현 계획의 조사 표에 기록했다. 50,000건을 검토하지 않았다.

실제 구현 전에는 부모가 발급한 편집 권한 범위, text+runs+override/fallback CAS, 전체 활성 입력 동안 DOM 보호, iframe 경로와 문구 소유 페이지 구분을 구현 계약에 반영한다. 이후 코드·IME·브라우저·저장 회귀 검증을 수행한다. 스크롤바·영문 홈페이지 시안은 이번 10개 CMS 직접 편집 시안에 포함되지 않는다.
