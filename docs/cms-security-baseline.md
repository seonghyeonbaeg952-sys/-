후원약정의 운영 DB 정책은 원본 SQL에 있는 금액/서명 제한보다 약했고, 동의 여부와 초기 상태만 검사했다. 새 마이그레이션은 실제 확인한 원본 필드·서명·역사적 레코드를 보존해야 한다.

## 이미 확인된 보호 장치

- 관리자 권한은 `profiles.role`과 서버 `is_admin()`을 사용한다. 사용자 입력 metadata로 권한을 정하지 않는다.
- 단원 공개 API는 이름 공개 범위에 따른 명시적 projection을 사용한다.
- 입단지원 v2는 서버 입력 검증, UUID별 멱등성, advisory transaction lock, 모집 안내 행 잠금과 서버 시각 검사를 이미 갖고 있다. 보완 과정에서 제거하지 않는다.
- 문의·지원서·후원약정의 원본 행은 공개 읽기가 차단되어 있다.
