# 영문 샘플 수정·조사 보고

2026-09-28. 적용 대상은 `/sample/`의 English 화면과 CMS의 개별 English 콘텐츠 관리입니다.

## 조사 범위

이번에 실제로 참고한 공식 자료는 아래 **18종**입니다. 자료 10,000건을 확인한 조사라고 주장하지 않습니다. 검색 결과 수·중복 URL·기능 후보 수를 실제 검토한 자료 수로 계산하지 않았습니다. 아래 추가 기능 30개는 공식 문서와 현재 코드/화면에서 도출한 이 홈페이지용 제안입니다.

## 수정한 문제

- 홈 악보 마지막 화면: 제목, 성부 이름, 오선, 본문, 버튼의 고정 좌표 충돌을 자연스러운 세로 배치로 변경했습니다. 기존 표시 시점·투명도·이동 변수는 유지했습니다.
- 홈 정신 궤도: 영어 제목 크기와 폭을 궤도 안에 맞춰 줄이고 CTA와 간격을 확보했습니다. 링·노드·사진 소스는 재정의하지 않았습니다.
- 정신 페이지: 한국어 기준의 고정 줄 높이와 큰 들여쓰기를 제거했습니다. 교육 본문과 인용 카드가 앞 문구의 실제 높이를 따르고, 성경 구절·가치 패널이 긴 본문에 맞춰 늘어나게 했습니다.
- 소개 페이지: 강조 제목의 한 줄 강제를 해제했습니다. 소개·창단 배경·교육 영역은 영어에서 그리드 흐름을 사용하므로 제목이 여러 줄로 늘어나도 사진이 그 아래 공간을 차지합니다.
- 후원약정: 영어 월 이름과 Month/Day/Year 입력, 윤년·유효한 날짜·네 자리 연도를 처리했습니다. 한국어 원래 입력과 서명 기능은 그대로입니다.
- CMS: 11종 콘텐츠마다 English 초안과 게시본을 분리했습니다. 제목이 같아도 종류와 UUID로 식별하므로 독립 편집합니다. 언어별 이미지/포스터/영상, 원본 fallback, 상태 표시, 저장된 콘텐츠 미리보기를 제공합니다.
- 갱신: 게시 내용이 같을 때 주기적 조회가 홈페이지 데이터 재생성을 일으키지 않게 했습니다. 영문 자료 조회 실패 시 재시도와 현재 콘텐츠 유지가 가능합니다.

## 20개 관점의 재검토 기록

검토 종류는 코드·CSS·상태 하네스·서버 렌더링·실제 DB/API입니다. 이를 실제 브라우저에서 20회 화면을 조작한 검사로 표현하지 않습니다. 컴퓨터 유즈 금지 지시 때문에 수정 후 픽셀 배치는 직접 조작하지 않았습니다.

| 15. 날짜 언어·유효성 | 영문 선택지, 1900/2000/2024/2026 윤년, 불완전 날짜 | 모델·실제 React 서버 렌더링 |
| 16. 버전 독립성 | 같은 원문 제목의 두 항목을 다르게 수정 | 콘텐츠 모델 + DB 트랜잭션 |
| 17. 이미지·영상 | 원본 fallback, 연결 ID/날짜/분류 보존, YouTube ID 검사 | 모델·API·기존 Storage 회귀 |
| 18. 저장과 게시 | 임시저장만으로 공개되지 않음, 연속 클릭/충돌 차단 | CMS 상태 하네스 + DB |
| 19. 권한·공개 범위 | 관리자만 초안 접근, 숨긴/삭제한 원본의 영어 공개 차단 | 실제 DB 역할 검사 + REST 읽기 |
| 20. 원본과 정리 | 원본 렌더 계약·DB 해시 유지, 테스트 행 롤백, 전체 회귀 | 원본 계약 + 해시 비교 + 프로젝트 테스트 |

반응형 검사는 기존 390/768/1440px 구성의 서버 렌더링과 CSS를 포함합니다. 이 검사가 브라우저의 실제 줄바꿈·사진 크롭·폰트 로딩 결과를 증명하지는 않습니다. 특히 CMS에서 임의로 아주 긴 제목이나 매우 큰 글꼴을 설정한 경우 픽셀 확인이 필요합니다.

## DB 및 API 확인

새 테이블은 `sample_english_content`이며 원본 데이터 테이블을 수정하는 RPC는 만들지 않았습니다. `scripts/verify-sample-english-content.sql`의 실제 DB 트랜잭션에서 초안 비공개, 게시, 동일 제목의 독립 버전, 오래된 저장/게시 거부, 비공개/삭제한 원본 제외, 관리자/비관리자/익명 권한을 확인했습니다. 모든 fixture는 ROLLBACK했습니다.

실제 익명 REST 요청에서는 게시본 조회 200 / 0건, 초안 테이블 직접 조회 401로 차단됐습니다. 원본 공지 1건, 갤러리 2건, 공연 1건, 원본 CMS 문서 3건은 검사 전후 전체 행 해시가 같았습니다. 검사 후 영문 콘텐츠 테이블은 0건입니다.

Supabase Advisor의 SECURITY DEFINER 실행 권한 경고는 공개 게시본만 반환하는 좁은 조회와 관리자 확인·버전 검사로 제한한 저장/게시 인터페이스에 해당합니다. 함수의 빈 search_path, 명시적 grants, 원본 공개 상태 필터와 실제 역할별 허용/거부 검사를 함께 확인했습니다. 이 검사를 경고가 전부 사라졌다는 의미로 보고하지 않습니다.
