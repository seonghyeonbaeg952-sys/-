# 한글 문구 균형 조정 · Figma / CMS 초안 인계

확인일: 2026-09-27. 공개 게시와 배포는 수행하지 않았다.

## 결과와 적용 경계

- CMS 저장 확인: **home v8 / spirit v8**. 공통 copy 129개(홈55, 정신74)와 정신 페이지의 모바일 전용7개를 읽어 되검증했다.
- 공개 published / published_at는 두 문서 모두 null이다. appearance는 기존 빈 객체 그대로이며, 기존 홈 모바일 소개 제목 “함께 빚어가는 화음, 세대의 노래”도 보존했다.
- 최종 추가 요청에 따라 짧아진 설명 33개 의미 단위를 보강했다. 키별로는37개 공통값이 달라졌다. 마지막 참여 안내는 원래 절대 위치에 맞춰2문장으로 재정리했다.
- PDF의 문구만 참고했다. PDF 디자인, 사진, 배경, 레이아웃은 가져오지 않았다.
- 제목과 버튼은 간결하게, 설명은 작품 이해·교회음악의 전통·배려와 책임·다음 세대 교육의 내용을 되살렸다. UX Writing 기준으로 설명형 “합니다/배웁니다” 말투를 통일했다.
- 공개 홈페이지의 CSS, 사진, 폰트, 색상, 기존 링크 목적지를 변경하지 않았다. 소스 변경은 기존 기본값을 유지하는 CMS 문구 연결과 관리자 미리보기 버그 수정이다.
- 기기별로 짧게 만든7개 모바일 값은 설명의 핵심을 유지하면서 원래 장식 숫자와 버튼 영역을 침범하지 않도록 한 예외다. 데스크톱/태블릿 성장 설명은 자세한 본문을 유지한다.

## 실제 CMS 버그 수정

1. 문구 편집 모드에서도 링크/버튼/탭의 보통 클릭은 실제 동작하도록 분리했다. 버튼 안 문구 선택은 Alt+클릭으로 가능하다.
2. 입력을 수정 중인 경우 내비게이션을 막고 편집을 마치라는 메시지를 유지한다. preview 메시지는 origin/source/nonce와 허용된 public route를 검증한다.
3. 관리자 캔버스 왼쪽 안내문과 오른쪽 배치 패널을 독립된 레이아웃으로 분리했다. 긴 패널이 왼쪽 도움말 사이 여백을 늘리던 문제를 제거했다.
4. 홈 입단4단계 문구가 원본 콘텐츠/CMS 기본값보다 강제로 한 단계로 축약되지 않도록 연결을 보완했다.
5. 새 연결은 기존 표현식·문구·태그·줄바꿈·링크의 기본 렌더를 보존하는 계약 테스트로 검증했다.

## 조사 기준과 남은 한계

[MDN word-break](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/word-break), [MDN white-space](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/white-space)를 확인하여 한글 단어 단위 줄바꿈과 명시적 줄바꿈을 구분했다. Figma 글자 재배치와 브라우저 CSS 줄바꿈은 같은 엔진이 아니므로 실제 CMS 검증을 병행했다.

물리적 iOS Safari/Android 기기는 이번 검증에 포함되지 않았다. 모든 모션 타임라인 프레임과 사용자가 이후 자유 편집하는 모든 길이를 보증하는 테스트가 아니다. 현재 확정 문구와 실제 검토한 상태에 대한 결과다. 영문 시안은 별도 작업의676페이지가 담당하며, 별도 인계문서를 유지한다.

## 복원과 보존

기존 CMS 문서는 로컬의 무시된 `artifacts/copy-revision/cms-before.json`, `cms-before-compact.json`, `cms-before-balance.json`에 보존되어 있다. 최종 `cms-final.json`은 실제 DB 재조회값이다. 기존 문서를 기대 버전과 함께 잠근 후 copy/deviceCopy만 병합하고 문서 validator를 통과시켰다. RLS/Auth/DDL은 바꾸지 않았다.

원본 PDF와 첨부 TXT는 보존한다. 이번에 만들었던17개 임시 PDF 렌더 이미지만 정리하며, 원본 PDF에서 다시 생성할 수 있다. 운영 데이터나 지원/후원 기록은 삭제하지 않았다.
