## UX 개선점

- 지원서 검토 후 제출, 문의 오류 시 입력 유지, 후원 검토 후 제출이라는 실제 순서를 시안에서 확인할 수 있습니다. 지원서의 이전 접수 결과 확인 상태는 모집 기간이 끝난 기존 요청 확인 상황임을 명시하고 수정 버튼을 비활성화한 예시로 표시했습니다.
- 문의 성공/오류는 별도 모달이 아니라 원본처럼 폼 안에 표시합니다. 후원 성공은 입력 필드 대신 문서 안내·완료 메시지·인쇄/새 약정 동작을 보여 줍니다.
- FAQ는 한 번에 하나만 열리는 코드 동작을 반영해 질문별 시안을 분리했습니다. 영상은 16:9 및 별도 YouTube 링크를 유지하며 사진의 이전/다음 버튼을 잘못 복사하지 않았습니다.
- 글자 폭을 줄여 의미를 빼는 대신 원문을 유지하고 높이를 늘렸습니다. 모바일 연습 시간은 요일과 시간 범위를 두 줄로 나눠 `PM`만 떨어지지 않도록 했습니다.
