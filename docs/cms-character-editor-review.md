## 10개 순차 검토

1. **정보 구조:** 검색 → 한 문구 선택 → 입력 → 선택 글자 서식 → 결과 확인으로 축소. 모든 입력칸을 동시에 열지 않는다.
2. **용어:** “페이지 전체 서식”과 “선택한 글자 서식”을 분리한다. `px`를 라벨에 표시하고 글꼴을 한글로 표시한다.
3. **선택 범위:** 선택 문구를 인용해 표시한다. 선택이 없으면 도구 비활성화, 전체 변경은 “전체 글자 선택”으로 명시한다.
4. **키보드:** native textarea의 Shift+방향키 선택, labelled select/number, 실행 취소/다시 실행 버튼을 사용한다. 도구로 포커스를 옮겨도 선택 범위를 유지하는 구현을 확인한다.
5. **모바일:** 390px 패널에서 입력은 342px, 도구는 줄바꿈한다. 캔버스 readback상 바깥으로 벗어난 직접 자식 0개, 버튼/입력 인스턴스 높이는 최소 44px다.
6. **글자와 줄바꿈:** Gothic A1을 CMS 기본으로 유지하고 선택한 “청소년”에만 함렛 32px 시안을 적용했다. 두 줄 문장이 잘리지 않는 스크린샷을 확인했다.
7. **회복:** 실행 취소, 다시 실행, 선택 서식 지우기, 항목 원문 복구를 구분한다. 내용이 바뀌면 범위를 재계산하고 원문 스냅샷이 맞지 않는 서식은 적용하지 않는다.
8. **저장 안전:** 시안에 초안/별도 게시 안내를 명시했다. 실제 저장·게시·이력은 기존 CAS 흐름을 사용하고 검증 범위를 넓힌다.
9. **팝업 날짜:** 잘못된 종료일 바로 아래 한국어 오류를 둔다. 같은 날과 빈 날짜는 허용한다. 모호했던 “취소·입력 유지하며 날짜 수정” 버튼은 “취소”로 정리했다. 저장이 거절되는 이유를 별도 설명한다.
10. **일관성/기본값:** 기존 Figma 입력·버튼 인스턴스 및 paper/ink/burgundy/border 토큰을 재사용했다. 흐릿하던 도구 버튼 경계선을 보완했다. UI에 노출할 서식 가능 문구는 실제 React 렌더링 연결 목록으로 제한한다. 공개 기본 DOM 회귀검사와 브라우저 검증은 별도 수행한다.
