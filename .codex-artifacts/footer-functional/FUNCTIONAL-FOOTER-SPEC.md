# SMYC 기능 중심 푸터 샘플

## 정보 구조

1. 브랜드와 즉시 행동
   - 서울모테트청소년합창단 로고·명칭
   - 대표 전화
   - `입단 안내`, `후원·문의`
2. 핵심 정보와 탐색
   - 한 줄 소속 설명, 주소, 대표 전화
   - 바로가기: 합창단 소개, 합창단 정신, 공연·소식, 갤러리
   - 참여: 입단 안내, 후원·문의, 오시는 길
   - 연결: YouTube, Instagram
3. 법적·보조 기능
   - 저작권, 재단 소속, 관리자 로그인, 상단 이동

## 반응형 동작

- Desktop 1536: 모든 메뉴를 3열로 항상 노출한다.
- Tablet 768: 연락처를 한 블록으로 합치고 메뉴를 3열로 유지한다.
- Mobile 390: 메뉴 그룹을 56px 높이의 접이식 행으로 전환한다. 기본은 닫힘이며 한 번에 하나만 연다.
- 모든 버튼과 모바일 메뉴 행은 최소 44px 터치 영역을 유지한다.
- `TOP`은 키보드 포커스와 스크린리더 이름을 제공하고 부드럽게 페이지 상단으로 이동한다.
- 외부 소셜 링크는 새 창으로 열고 시각적 `↗` 표시와 접근 가능한 새 창 안내를 함께 제공한다.
- 관리자 로그인은 일반 방문자 동선과 경쟁하지 않도록 최하단 보조 링크로 둔다.

## 조건부 영역

- 파트너가 등록된 경우에만 내비게이션과 법적 정보 사이에 로고 스트립을 노출한다.
- 소셜 링크가 없으면 빈 문구를 표시하지 않고 해당 칩만 생략한다.

## 시각 원칙

- 장식용 글로우, 콜라주, 대형 영문 타이포, 감성 히어로를 사용하지 않는다.
- 딥 차콜 배경, 아이보리 본문, 오렌지 상태·행동색만 사용한다.
- 한국어 UI는 Gothic A1, 브랜드명만 Hahmlet Bold를 사용한다.
- 구분선, 대비, 정렬로만 정보 위계를 만든다.
